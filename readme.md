## Motor Imagery Classification

This script implements the classification. It implements the VGG16 and Inception V3 TL models.

Dataset: The dataset and its according published paper can be found on this [open-source project](https://www.bbci.de/competition/iv/#datasets). 

Published paper: The findings of this project has been published in [2022 24th INMIC](https://ieeexplore.ieee.org/document/9972989).
